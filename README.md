## Overview

Word goal plugin for document editor helps tracking your writing progess without a need to check document stats from time to time.

### Installation:

Install the plugin according to the [official ONLYOFFICE plugin installation guides for Desktop Editors][1].

### Working with plugin:

After installation go to *Plugins* tab and start *Word goal* plugin. Set your custom goal if needed. Default word goal value is 500 words.

### Note:

* Plugin works globally, i.e. your custom goal will apply for all documents and remains after closing the editor.
* You can switch between any other tabs on the left panel and the progress still will be tracked.

[1]: https://api.onlyoffice.com/docs/plugins/development-workflow/installing-and-testing/desktop-editors-installation/
